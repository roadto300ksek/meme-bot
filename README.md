# Meme Bot — Telegram-бот с модерацией и планировщиком публикаций

Бот для ведения тематического канала: собирает мемы из папки, отправляет их админам на модерацию и публикует одобренное равномерно в течение дня с дневным лимитом.

## Что умеет

- **Индексация контента** — сканирует папку с мемами, поддерживаемые форматы, дедупликация по SHA-1.
- **Модерация** — отправляет мем админам, хранит `pending`-запросы (`chat_id`, `message_id`), обрабатывает одобрение и отклонение, защищает от дублей и параллельных запросов на один мем.
- **Планировщик** — алгоритм равномерных слотов: дневной лимит, активные часы (по умолчанию 9–23), очередь на 14 дней вперёд, отложенные посты.
- **Устойчивость** — состояние в SQLite, восстановление очереди после рестарта, истечение старых `pending`.
- **Статистика и администрирование** — счётчики по статусам, очистка и сброс очереди.
- **Автотесты** — 14 сценариев на изолированной БД, без обращения к боевой базе и Telegram.

## Стек

- Python 3
- aiogram 3.13
- aiosqlite (SQLite, асинхронный доступ)
- APScheduler
- Flask (health-check / keep-alive при деплое)
- python-dotenv, aiofiles

## Структура

```
bot.py        — хендлеры, модерация, публикация
database.py   — схема и запросы: мемы, pending, расписание, настройки
scanner.py    — индексация папки и дедупликация по SHA-1
utils.py      — хеши, время, допустимые расширения
config.py     — валидация переменных окружения
tests.py      — автотесты
```

## Запуск

```bash
pip install -r requirements.txt
```

Переменные окружения (`.env`):

```
BOT_TOKEN=...
ADMIN_IDS=111111111,222222222
CHANNEL_ID=@your_channel
MEMES_PATH=./memes
DAILY_LIMIT=5
SCAN_HOUR=0
MODERATE_HOUR=9
```

```bash
python bot.py
```

## Тесты

```bash
python tests.py
```

Тесты создают временную БД, проверяют дедупликацию, модерацию, блокировку параллельных `pending`, алгоритм слотов, дневные лимиты и полный цикл «модерация → очередь → публикация».

## Что демонстрирует

Асинхронный Python, работу с SQLite без ORM, проектирование состояний и переходов, алгоритм распределения слотов, обработку граничных случаев и автотесты на реальную логику, а не на моки.
